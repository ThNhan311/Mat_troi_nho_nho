# Script onboarding nháp nội bộ

Năm script trong bản làm việc nội bộ là bản nháp, trạng thái **BLOCKED / RUNTIME_NOT_VERIFIED**; chúng không được đưa vào bộ công bố mặc định. Không dùng cho onboarding chính thức, không bỏ chốt chặn. Nếu nhóm tiếp tục automation sau này, cần hoàn thiện xác minh Docker context/image/instance, artifact và datasource, wrapper seed, chuỗi PID/listener, secret handling, rồi review và kiểm thử cô lập riêng. Báo cáo nội bộ không mặc định được công bố.

Hướng dẫn bàn giao đề xuất là [manual quickstart](../12_MANUAL_QUICKSTART.md). Khi công bố bộ tài liệu mặc định chỉ stage README này, không stage năm script nháp.
